## 📌 Sobre o projeto

Aplicação web desenvolvida em PHP que permite ao usuário descobrir seu signo zodiacal a partir da data de nascimento.

Este projeto foi desenvolvido como atividade prática da disciplina de **Programação Web**, com foco na integração entre front-end e back-end.
